# Sujal Jadiya — AI/ML Portfolio

A responsive portfolio for AI/ML, Machine Learning, Data Science and Data Analytics. Built with plain HTML, CSS and JavaScript; no build step or package installation is required.

## Files

- `index.html` — accessible portfolio content and metadata
- `style.css` — dark responsive design, interaction states and reduced-motion support
- `script.js` — mobile navigation, scroll reveals and current copyright year
- `profile.jpeg` — circular hero portrait

## View locally

Open `index.html` in a modern browser. Keep all four files in the same folder so the stylesheet, script and portrait load correctly.

## Publish with GitHub Pages

1. Add these files to the root of a GitHub repository.
2. In repository **Settings → Pages**, choose **Deploy from a branch**.
3. Select the publishing branch and `/ (root)`, then save.

The portfolio uses the supplied email, LinkedIn and GitHub profile. The three named repository links are Heart Disease Prediction, Insurance Cost Prediction and Superstore Sales Analysis. Other project cards link to the GitHub profile because no specific repositories were supplied for them.
