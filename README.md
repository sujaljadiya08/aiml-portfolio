# Sujal Jadiya — AI/ML Portfolio

A responsive, static portfolio for Machine Learning, Data Science, Python and analytics work. It is built with plain HTML, CSS and JavaScript and is ready to publish with GitHub Pages.

## Files

- `index.html` — portfolio content and metadata
- `style.css` — responsive layout, visual styles and reduced-motion support
- `script.js` — mobile navigation, reveal effects and dynamic copyright year
- `profile.jpeg` — hero portrait

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages

1. Push these files to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Open the Pages URL shown in repository settings.

## Before publishing

- Add your LinkedIn URL and a resume PDF if you want those links on the site.
- Replace the general GitHub links on Video RAG, Customer Churn and House Price Prediction with their specific repositories when available.
- If you have live demos, add their URLs to the relevant project cards.
- Verify the linked repository names and project descriptions match the latest versions of your work.

The current contact email and GitHub profile are populated from the supplied portfolio content.
